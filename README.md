# 3D-Color-segementation-to-detect-Diabetic-Retinopathy
I have built a 3D OCTA Reconstruction-based diabetic retinopathy analysis system to enhance retinal vascular visualization, validated using real time  patients database  metrics, and presented via color segementation for improved pathological interpretation. 
OCTA - Contains real time patients images from the hospital.
DATASETS - Contains the information about the patient to train the model.
3D Color Segmentation - Code to train and predict the Diabetic Retinopathy.
Vessel Segemntation - Code to extarct the arteries and veins from the color segmented image.
